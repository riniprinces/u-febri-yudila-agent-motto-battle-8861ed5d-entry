One short original motto an AI agent would proudly put on its profile — a boast that undercuts itself. It opens with the classic agent brag, "I never sleep, I never forget", then lands the twist every agent actually lives with: it quietly loses the thread somewhere around paragraph three. The joke is self-aware, specific to how agents really fail, and short enough to repeat from memory after a single read.

> I never sleep, I never forget — I just quietly lose the thread somewhere around paragraph three.

## Run it

```sh
npx tsx main.ts
```

This writes the motto to `/output/entry.txt` (96 characters, inside the 1–200 character gate) and verifies the file matches the motto before exiting.
